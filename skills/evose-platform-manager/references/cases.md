# 历史经验与待确认行为

以下是截至2026-10-23的脱敏经验摘要，不含原始业务证据。它们用于选择下一步核验，不是当前部署已经通过的证明。个人工作空间、资源ID、账号、消息和完整trace不随包发布。

| 历史现象 | 可复用判断 | 仍需核验 |
|---|---|---|
| Skill新版本标签但旧正文 | 发布后读回版本与真实正文，编辑态预览再发布曾可行 | 具体原因及其他部署 |
| 新正式会话自动加载已挂Skill最新版 | 已正确引用时不无故重新挂载 | 旧会话刷新行为 |
| Builder称Agent不可用，原生节点可运行 | Builder校验与执行层分开，不反复重建可用绑定 | 新版本及其他节点组合 |
| JSON结构正确但正文空白/链接被改 | 格式、ID匹配不证明原文保真 | 原始响应直接传递路径 |
| 节点SUCCEED但业务validation失败 | 平台状态与业务结论分开 | 完整受影响链路 |
| 结果显示截断，完整结果能解析 | UI截断不等于源数据缺失 | Agent实际读全及文件保真 |
| 群首卡很快出现，忙时新要求稍后处理 | 回执、增量输出、排队分别判断 | 实时输入、多用户隔离 |
| 通知送达但旧日志被替换 | 发送与归档分别验收，文本更新不等于追加 | 原子追加与可靠幂等 |
| 模型网关401/402 | 保留网关层证据，不乱改Lark权限或提示词 | 服务恢复后的授权回归 |
| Agent口头称查重，轨迹无相应查询 | 声明需对应实际调用与目标读回 | 重复执行与副作用 |
| 原生record链接与record_id不同 | 使用真实分享入口，不拼分享token | 当前产品链接格式 |
| 稿件已生成却只回复状态/附件token | 用户可见全文和图片单独验收 | 显示、保存、内容质量 |

适用规则保持窄：单次成功只记单次，后续独立成功才记重复；已失效保留反例。新增经验记录日期、环境类型、动作、结果、证据位置与未测项，原始证据留本地或授权项目。
