# 测试与评测

测试针对当前改动与真实目标，不为补齐经验库擅自生成、写库、发送或清空数据。

## 验收层次

| 层级 | 证明范围 | 不能替代 |
|---|---|---|
| 本地结构检查 | frontmatter、引用、脚本与格式 | 真实平台功能 |
| 发布与加载 | 版本、正文和绑定正确 | 业务成功 |
| 只读运行 | 当前样本工具可用、事实读取与判断 | 写入、上传或恢复 |
| 真实执行＋独立读回 | 指定记录、附件、状态符合预期 | 长期稳定、并发恰好一次 |
| 用户可见成品 | 全文、图像、文件实际可审阅 | 业务保存与内容事实正确 |

修改前定义预期、版本、真实入口和不变项，保留回退点。先测变化节点/Agent，再从用户实际入口验证受影响链路；嵌套场景核对上层绑定，不能只测下层调试页。

涉及写入在已授权隔离目标实写并独立读回。需要验证幂等性时重复相同业务输入，检查新增/覆盖/重复附件与调用；没有重复试验不称幂等通过。服务、余额或权限阻塞明确待验收，用户暂停后停止。

“干净测试”不等于清空生产库。只处理指定测试数据，保留原始备份和回执。首次生产用新会话，恢复测试沿原任务和同一作品；不把手改prefill后的成功说成原输入自主通过。

## 按缺陷选样本

| 问题 | 预期与证据 |
|---|---|
| 布尔门槛 | true、false、null、缺失、字符串不混用；按真实字段类型 |
| 矩阵映射 | 依据本次字段元数据，保留空位，乱序仍可正确还原 |
| 关键资料缺失 | 先读上下文和关联，再问真实缺口，不猜事实 |
| 图文交付 | 当前版本正文、简报、真实图与附件、正确状态共同验收 |
| 上传中断 | 复用原图/token，先查是否已归档，不重复生成 |
| 异步超时 | 保存真实任务引用，恢复先查原任务 |
| 返工与采用 | 同一作品保留旧版，旧确认不自动批准新版 |
| 自然语言 | 当轮候选、上下文承接、局部修改和真实成品展示 |
| 子调用 | 输入、版本、允许范围、返回与副作用分别核对 |
| 并发 | 只有真实原子保证与运行证据才声称可靠 |

要测附件不必重跑上游研究，要测归档不重新生图。测试费用和外部影响遵守任务范围。

## 原始事实与保真

完整读取工具参数与响应，外层成功不证明内层数据存在。更新payload漏字段不是平台已经回填。请求未知先查状态，不立刻重复非幂等提交。

矩阵按响应field_id_list/fields映射，不能按视图列序、请求顺序或模型手排JSON。字段描述不证明类型；现场schema与元数据优先。代码校验模型重抄结果不能证明源数据未串列。

原始响应、模型输出、最终文件分别比较。structured_output可解析不等于逐字保真；来源正文可能丢链接、空白或精确长度。必要时用固定代码截取并记录输入/存储长度，明确节选、未知时间及model_generated，不靠重复让模型保证字符数。

内联显示截断先取完整结果。文件HTTP200和DOM可读只证明可取得内容，不能替代视觉或数据验收。无法截图时明确未做视觉检查。

时间转成时间戳比较，保留来源秒数与时区。字段显示分钟不应丢秒；观察时间不能用历史自报时间代替，迟到采集不冒充准点历史快照。日期级发布时间不能直接算精确小时节点。

## 独立业务核对

核对真实对象、关联、业务键、渠道、必填字段、当前附件、来源链接与状态；保存前后人工字段保持授权范围。旧图不代替当前版本，版本号不代替可恢复全文与素材。

报告统计、逐条快照和文案各自验收。汇总正确不证明明细完整；无相邻期正文不能编造内容趋势，无同窗口数据不将累计数当同窗对照。曝光/粉丝比不是独立触达率，单帖相关性不是因果。

来源主路径缺席不证明删除。对已知历史例外按ID核查，区分窗口外、不可读、备用空与未覆盖；分页耗尽不代表所有历史条目已验证。失败不能填0，NotFound不直接写删除。

## 记录结论

分别报告配置保存、版本/绑定、节点、整链路、业务读回和用户可见交付。保留输入、版本、真实运行引用、样本范围、错误、人工介入和未测项。人工纠错后通过不称无人干预首次通过。

一次通过率、修复后通过率、无效调用、重复生成、时长与成本按可获得证据计算。模型自填日志时间不可靠；无usage/账单就标未测，不估造降本比例。测试结论不授权继续修改线上配置。
