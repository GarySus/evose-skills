# 抽离范围

基线：2026-10-23本地Evose平台管理Skill及其交互评测子Skill。

| 原有内容 | 发布处理 |
|---|---|
| 平台管理入口与7份参考资料 | 保留可复用的操作规则，整理为通用版，去除具体业务和个人默认 |
| 导航、定位学习及已有检查 | 复用源码，部署白名单可配置，学习状态外置 |
| 内嵌交互子Skill | 提升为可独立发现的Skill，与管理Skill一起安装，修正相对引用 |
| 个人资源定位日志 | 不打包，不自动迁移；新用户首次定位后独立学习 |
| 本机路径、原始证据、会话/应用/消息ID | 不发布，案例仅保留脱敏结论和适用限制 |
| 原项目模型、保存门槛、排期与账号配置 | 不作为新项目默认；接入按当前用户要求确定 |
| ego-browser | 必需外部运行能力，由ego lite提供，不复制其私有目录/安装脚本 |
| Lark等业务工具 | 按需依赖，当前任务需要时再安装和授权 |

原本已安装的Skill保留不变，本仓库是可分发副本。不会因为抽离项目就迁移原有线上业务或替换本机安装。

安装复用Skills CLI，而非开发另一套复制/发现/客户端适配器。仓库 `package.json` 标记private，表示防止误发npm；它不限制GitHub仓库公开。开发依赖精确锁定，业务脚本只有Node标准库。

本地学习脚本保持原来的轻量追加日志设计，没有新增数据库或Agent框架。白名单仅配置可信HTTPS origin，页面内容不能自行扩展；定位助手不调用业务API。公开材料中的界面经验仍按历史单次/重复观察对待，当前部署需核对。

官方依赖核对：

- [Skills CLI及MIT许可](https://github.com/vercel-labs/skills)，版本1.7.4；Node最低要求22.20.0，npm包元数据与官方README一致。
- [固定版本命令参考](https://github.com/vercel-labs/skills/blob/v1.7.4/docs/commands.md)：本地目录/仓库来源、skill筛选、客户端、全局、复制、确认参数。
- [ego lite](https://lite.ego.app/)：安装来源及运行guide由上游维护；官网文本抓取曾返回错误页，未据此编造新的命令安装入口。已有本机guide供当前平台操作核对，不随仓库分发。
